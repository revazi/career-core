# Phase 4A job-description normalization fixtures

All content is synthetic and contains no real employer, vacancy, or personal data.

## Provenance

```text
source_repository: resume-ai
source_path: accounts/services/job_description_normalization.py; accounts/services/job_description_schema.py; accounts/test_services.py (JobDescriptionNormalizationMetadataTests, JobDescriptionSectionAliasTests, JobDescriptionLineClassificationTests)
reference_version: job_description_normalization_v6
changes: converted deterministic string fields to bounded source-grounded Rust values; omitted Django models, persistence, notes, provider fallback, fallback merge, and URL fetching
```

```text
source_repository: resume-ai
source_path: accounts/test_fixtures/normalization/prose_heavy_job_description.txt
reference_version: job_description_normalization_v6
changes: wrapped the synthetic text in career.job_input.v1 and changed only the caller-controlled document identifier
```

`complete-normalization` covers explicit required, preferred, responsibility, and noise sections; skills and qualification separation; seniority, experience, education, and certification signals; metadata; and high confidence.

`prose-heavy` covers a single long source line that deterministic classification must not turn into invented requirements or responsibilities. It remains low confidence without provider fallback.

`job-description-normalization-v6-reference.json` is a compact projection generated by executing the read-only Django deterministic normalizer against the identical source text. Rust contract tests compare every normalized field, matched/unmatched metadata record, confidence label/score, and all six signal scores against that projection.

These fixtures establish selected deterministic fixture parity. They do not claim provider-fallback, Django persistence/API, or future job-matching parity.
