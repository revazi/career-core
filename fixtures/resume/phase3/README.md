# Phase 3 resume-analysis fixtures

All documents are synthetic and contain no real personal data.

## Provenance

```text
source_repository: resume-ai
source_path: accounts/services/resume_scoring.py; accounts/services/resume_analysis_response.py; accounts/test_services.py (ResumeScoringServiceTests)
reference_version: deterministic_v2
changes: mapped synthetic career-core Phase 2 source text through resume_normalization_v1; compared the resulting equivalent normalized fields against the reference scorer; omitted Django models, persistence, timestamps, UUIDs, credits, and LLM interpretation
```

`complete-analysis` exercises high-confidence checks, weighted category aggregation, source evidence, deterministic strengths, and a confirmed improvement action.

`messy-analysis` exercises low-confidence score floors, provisional findings, deterministic fallback provenance, bounded warnings, and baseline-only scoring.

`deterministic-v2-reference.json` is a compact projection generated by executing the read-only Django scorer against normalized facts equivalent to the two Rust fixtures. A Rust public-contract test independently compares every check score, pass state, detection status, explanation, category score, and overall score against that projection.

Together these fixtures establish selected fixture and scoring-rule parity; they do not claim end-to-end Django parser or API-response parity.
